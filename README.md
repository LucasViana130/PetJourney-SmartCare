# PetJourney SmartCare

## Descrição
Sistema IoT para monitoramento preventivo da saúde animal.

## Tecnologias
- ESP32
- Wokwi
- MQTT
- HiveMQ
- Node-RED

## Funcionalidades
- Monitoramento de temperatura
- Monitoramento de BPM
- Dashboard em tempo real
- Alertas automáticos

## Arquitetura
ESP32 → MQTT → Node-RED → Dashboard

## Como executar

### Instalar Node-RED
npm install -g node-red

### Rodar
node-red

### Dashboard
http://localhost:1880/ui
